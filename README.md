# simple RPG game engine

fixed screen resolution (16x12 tiles / 256x192 pixels)

fixed tile size (16x16)

The game engine allows you to:
- Easily edit a `gamedata.json` file.
- Export a `build.zip` containing the gamedata, all relevant pngs, and an `index.html` file that reads the gamedata/pngs and runs the game.

I wanna tell stories! I wanna make worlds! I wanna flesh out unique characters and write interpersonal interactions!

No items/key items/equipment, money, leveling, etc. You get stronger by
unlocking new combat moves as you progress through the story.
Healing moves fill the role of healing items (since moves take up energy,
there's still an economy-of-health).
Battles only end when all enemies are defeated; there're no complex win
conditions or scripted losses or dialogue during battles.
